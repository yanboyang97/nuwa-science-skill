核查日期：2026-10-25。本文件区分方法资料支持的透明记录原则与本次设计的贡献比较流程。

## 本次设计与可被否定的预期

- **贡献分解与近邻矩阵：** 将复杂的“有无创新”问题落实到可比较的内容。若拆分掩盖了关键组合关系、或只比较词语而未比较方法，应调整分解。
- **优先检验最强覆盖证据：** 防止确认偏差。若近邻明确覆盖主张却因作者不知名、引用少或全文难取而被忽略，流程失效。
- **区分未检出、证据不足与实质差别：** 保留有限检索的认识边界。若报告把任何一种状态直接写成“首次”，应收窄结论。
- **不把组件先例等同组合先例：** 判断组合必须比较其关系与作用；反过来，简单并列已知组件也不自动证明有科学贡献。
- **版本与截止日匹配：** 防止拿之后公开的工作裁定某个过去日期的已知状态；不同公开时间应分别核对。

上述比较结构是本次工作流设计，未借用法律专利标准，也未验证其查全率或判断准确率。

## 创建者场景走查

以下是人工推演，非独立实测。

| 输入 | 预期决策与走查结果 |
|---|---|
| “帮我核查这个方法的创新点是否已经有人做过” | 应触发，先精确贡献再找近邻，形成有定位的覆盖判断 |
| “概述这个领域的十篇论文” | 不自动触发原创性审查；一般文献综合即可 |
| 查询没有结果，但只用了用户自创名称 | 补查通用概念、替代表述及相邻领域；仍无结果也不证明首次 |
| 摘要未提某个方法组件，全文无法访问 | 保留潜在近邻并标待核，不推定组件不存在 |
| A、B 组件各有论文，但组合关系未知 | 区分组件覆盖与组合覆盖，不向任一方向作无依据推断 |
| 用户只允许本地资料 | 结论限于给定集合，外部新颖性未核查 |
| 用户主张首次，但找到较早同类方法 | 直接指出覆盖，保留有证据的剩余差别，不迎合首次性 |

真实小任务：2026-10-25，未参与编写的试用者实际检索、阅读近邻原文并核对首稿/修订稿/会议版，对密度比加权校准残差的候选确认已有直接覆盖；记录了首稿具体公式、公开时间、贡献边界和失败的检索过滤。没有把未检出当首次，也未进行全球历史优先权穷尽调查、专家效果评判或跨学科比较。详细任务记录单独保存；结构检查不代替真实执行。

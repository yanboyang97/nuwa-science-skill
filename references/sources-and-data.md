# 资料来源与数据采集指引

用于创建或改进专业科研 skill 时确定“在哪里找、找什么、提取什么”。这里的数据包括文献、研究产物、过程记录和经验材料，不限于数值数据集。

默认先用已提供且相关的材料，再按缺口补充公开来源；先做一轮定向采集，重点覆盖方法依据、实际案例、局限或反例。按目标选择类别，不要求每次搜齐全部类型，也不设固定来源配额。用户已有来源、语言、时间或预算要求时优先遵守。

## 1. 元 skill 用来学习和设计能力的材料

| 材料类型 | 去哪里找 | 主要提取什么 |
|---|---|---|
| 方法学论文、教材、手册与研究指南 | 学术检索库定位原文；出版社、学会、大学图书馆及课程官网 | 操作步骤、适用前提、方法选择依据、评价与停止条件 |
| 完整研究案例、综述和学位论文 | 原始期刊或会议页面、作者主页、机构知识库；同时查看附录和补充材料 | 如何形成问题、组织已有知识、选择方法、检验解释；只提炼材料实际展示的过程 |
| 研究者原始讲座、访谈、长文与博客 | 作者或实验室主页、会议教程、大学课程；作者或主办方发布的视频、音频及文字稿 | 取舍理由、启发式、被追问后的解释、方法演变和未写进论文的实践经验 |
| 实验室实践、协议和工作流 | 实验室公开手册、方法附件、作者维护的仓库、公开研究协议和预注册 | 输入输出、关键步骤、检查点、实际约束和依赖条件 |
| 公开评审、作者回复与争论 | 期刊公开评审页面、OpenReview 等公开记录、原作者回应和修订版本 | 批评如何对应主张和证据，哪些修改解决问题，哪些分歧仍存在 |
| 失败、负结果、复现与更正 | 复现论文、负结果研究、作者复盘、仓库问题记录、出版社更正或撤稿说明 | 失败触发条件、原因与替代解释、补救措施、结论需要收窄的边界 |
| 真实任务过程与反馈 | 用户提供或授权的研究笔记、检索记录、代码和实验日志、版本差异、专家批注 | 原输入、实际行为、预期差异、改进前后结果；用于修正规则 |
| 可核验的练习、示例与评价材料 | 方法教程的配套案例、官方基准与评价仓库、带依据的专家标注和用户参考答案 | 任务、预期产物、判定依据、难点；留出未参与规则提炼的任务用于试用 |

研究者回忆与访谈可以帮助理解其判断，但不能补足没有记录的实验事实。用户给出的目标与偏好用于设计约束，不能当作方法已经有效的证据。

## 2. 专业 skill 实际工作需要的数据

按生成能力的用途裁剪，并把相应查找入口和提取字段写入该 skill。

| 数据类型 | 常见来源 | 需要保留的信息 |
|---|---|---|
| 文献元数据与检索记录 | 学术索引、DOI 记录、文献库、实际检索过程 | 标题、作者、日期、标识、版本、检索式、筛选理由和覆盖范围 |
| 全文、附录与补充材料 | 原始发表页面、作者稿、机构或学科资料库 | 精确到章节、页码、公式或图表的依据；注明只读摘要或局部的情况 |
| 问题、概念、定义与理论前提 | 原文、教材、标准及原始理论文献 | 定义、假设、分析层次、适用条件，以及同名异义或异名同义 |
| 方法、设计与结果 | 方法章节、协议、数据说明、结果图表和推导 | 对照、样本或数据范围、划分、指标、误差与不确定性；理论研究保留推导前提和反例 |
| 研究之间的关系 | 原文引用语境、参考文献、引用追踪和直接比较研究 | 谁在什么前提下支持、质疑或扩展哪个主张；引文边本身不等于支持关系 |
| 可复现产物 | 作者关联的代码仓库、数据集存档、领域官方数据库、实验和分析记录 | 版本、配置、数据来源、处理过程、运行入口和实际产物；明确哪些确实执行过 |
| 计划、评审、修订与状态 | 预注册、公开评审、作者回复、论文版本及更正撤稿记录 | 计划与实际的差异、修订原因、当前状态，以及争议影响的具体主张 |
| 任务上下文与评价依据 | 用户问题、已有材料、使用者需求、参考案例和资源限制 | 目标、可用输入、需要的输出、成功标准；未知处采用已说明的合理默认值 |

事实依据不足时标明缺口。不要用未公开的原始数据、不可得的评审或模型生成的内容填补缺失。

## 3. 具体入口与默认检索路径

这些是可用入口示例，不是固定白名单。按学科、语言和当前工具选择；入口说明核对日期为 2026-10-25，实际访问与覆盖范围以运行时为准。

| 用途 | 入口与说明 | 如何使用 |
|---|---|---|
| 已有材料与笔记 | 用户文件、相关项目资料、已连接的 Zotero 或其他文献库 | 先找原文附件、批注和已有失败案例；本地保存不会自动提高证据等级 |
| 学习调研与综合方法 | 大学图书馆研究指南，如 [Michigan 文献综述指南](https://guides.lib.umich.edu/litreview)；学科教材、学会和出版社方法资料 | 寻找目标能力的可执行方法与案例，保留适用学科和前提 |
| 课程、教程与研究经验 | [MIT OpenCourseWare](https://ocw.mit.edu/about/)、大学课程、会议和实验室官网、研究者原始博客或访谈 | 从机构或作者页面追到原始资料；视频和音频记录时间点，字幕疑点回查原片段 |
| 综合发现与引文追踪 | [Google Scholar](https://scholar.google.com/intl/en/scholar/help.html)、[OpenAlex](https://help.openalex.org/data/works/)；当前可用的论文检索工具如 SciSpace | 用题名、问题和关键词找候选，再沿参考文献与被引关系补查；不把检索摘要当成全文 |
| 标识、版本与元数据核对 | [Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)、原始发表页与 DOI 链接 | 核对记录及出版后更新，去除重复版本；元数据不能证明论文结论 |
| 学科内文献与全文 | 按领域选择数据库、学会和出版社；例如 [PubMed](https://pubmed.ncbi.nlm.nih.gov/about/) 用于生物医学发现，[arXiv](https://info.arxiv.org/about/index.html) 用于其覆盖领域的论文与版本 | PubMed 记录与全文获取分开处理；arXiv 收录不等于已由 arXiv 同行评审；核查所用版本 |
| 公开评审与作者回应 | [OpenReview](https://openreview.net/about)、期刊提供的公开评审历史 | 按实际公开范围读取评审、回复与修订，核查评论指向的原始证据 |
| 代码、数据及研究产物 | 论文或作者链接的 GitHub 等仓库、[Zenodo](https://help.zenodo.org/docs/deposit/about-records/)、领域官方数据存档 | 追溯作者关联、版本和实际文件；存档服务收录不代表已验证结果 |
| 研究计划与预注册 | [OSF Registrations](https://help.osf.io/article/330-welcome-to-registrations)、领域注册平台和论文关联的协议 | 对照预先记录的假设、方法和分析计划与最终报告，不推定所有附件公开 |
| 更正、撤稿与反证线索 | 出版社通知、原作者说明、[Crossref／Retraction Watch](https://www.crossref.org/documentation/retrieve-metadata/retraction-watch/) | 查询状态与原因，回到通知和相关证据判断影响范围；没有查到记录不能证明没有问题 |

中文与其他语言材料按任务需要检索原始渠道。研究者在公众号、知乎、B站、YouTube 或社交平台的原创内容可以作为经验或线索；核对作者、原始发布与上下文，不按平台名称一概判定可信或不可信。二手解读追到它引用的原文。

优先使用当前已提供且适合任务的文献库、论文检索、全文阅读或网页工具；工具不足再采用可用替代。不要假设某个插件、数据库订阅、全文或接口一定可用，也不把这份入口表变成安装清单。

## 4. 能力需求如何对应两层数据

| 要创建的能力 | 构建时重点学习 | 运行时重点读取 |
|---|---|---|
| 文献调研与新颖性核查 | 检索方法、筛选与遗漏案例、相关领域综述实践 | 检索记录、元数据、关键全文及其版本、纳入排除依据 |
| 文献串联、概念对齐与理论综合 | 综合方法、完整示范综述、概念混淆的失败案例 | 定义、前提、方法、证据和原文引用语境 |
| 交叉评议与证据审查 | 公开评审与回复、方法学批评、复现和更正案例 | 待评主张、比较条件、原始方法结果、评议及反证 |
| 问题发现与假设生成 | 研究问题形成案例、研究者判断过程、负结果与未解争论 | 已有发现、矛盾、失效条件、限制及候选解释；后续检索核查空白 |
| 研究设计与路线选择 | 方法指南、协议、预注册、方案取舍和失败复盘 | 目标、假设、可用材料、对照指标、资源约束和可区分解释的证据 |
| 复现与结果核验 | 复现工作流、实际差异记录、工具与数据说明 | 论文方法、代码版本、数据、配置、日志与输出 |
| 论证组织与学术写作 | 原始写作指南、示范论文及修改反馈 | 本次研究问题、证据、推论、目标读者和交付要求 |

例如，创建“文献串联 skill”时，方法指南与示范案例帮助形成操作规则；该 skill 运行时，应读取待分析论文的概念、假设、证据和引用语境。不能只收集领域论文摘要，就宣称已经提炼出串联方法。

## 5. 默认采集与记录方式

1. 明确本次缺的是方法、案例、反证还是运行数据。先查已有材料，避免重复采集。
2. 以目标能力与问题构造检索：概念及同义词，加方法、教程、评议、复现或失败等限定词。按需尝试原文语言及英文，不仅搜索“skill”或“提示词”。
3. 从候选记录追到原始全文、附件或产物。按 DOI、题名和版本关系去重，避免将同一研究的预印本、正式版和转载算作多份独立证据。
4. 提取会改变规则或评价的内容，并保留原文定位和反例。对关键缺口做定向补查；新材料不再改变操作、边界或检验方案时结束本轮，报告覆盖限制。
5. 原入口不可访问时，依次尝试作者稿、机构或开放资料库、已授权文献库。仍不可得就标记缺失并完成可支持部分；只有缺失使核心任务无法继续时才向用户索取必要信息。

最小记录包含：材料标识、类型、用途（构建或运行，可兼有）、原始来源与日期／版本、实际阅读范围、精确定位、支持的规则或主张、局限。检索任务另记平台、检索式、时间范围及关键筛选理由；按 [提炼与检验方法](extraction-framework.md) 保存必要依据。

## 6. 按用途判断证据

- 正式研究与实际产物用于核查相应主张；出版、收录或有 DOI 都不能代替内容核验。
- 讲座、访谈、博客、实验室实践和回忆用于提取经验与判断，标为经验建议或作者自述；迁移后仍需检验。
- 评审、问题讨论和批评提供检查方向；回到其针对的证据，不把评论直接当作最终裁决。
- AI 摘要、自动关系图和模型推断可辅助发现线索，不能升级为独立研究证据。
- 同时考虑来源与主张的直接关系、方法有效性、版本、独立性和可复查程度；不使用一个固定排名处理所有材料。

生成的专业 skill 应携带与自身用途有关的资料入口、类型、提取字段、访问失败处理和证据说明。较长时保存为随包参考文件；不照搬完整入口清单，也不依赖元 skill 目录中的私有相对路径。

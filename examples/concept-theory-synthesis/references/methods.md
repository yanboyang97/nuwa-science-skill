# 方法依据与检验记录

创建日期：2026-10-25。本技能将概念对齐与按需理论综合放在一起，因为清楚的定义、层次和前提是综合关系的必要输入；不要求所有对齐任务都提出新理论。

## 原始方法来源

| 来源与阅读范围 | 采用的有限要点 | 改编与边界 |
|---|---|---|
| Jabareen, 2009，[Building a Conceptual Framework: Philosophy, Definitions, and Procedure](https://doi.org/10.1177/160940690900800406)：Defining concept and conceptual framework、Conceptual framework analysis technique 的过程及 Phase 3–8、Concluding thoughts 的相关段落 | 分解概念属性与前提、明确关系并迭代检查框架 | 原文是跨学科社会现象的质性方法。本技能不照搬其对所有“框架”的定义，不把解释性综合当普适预测模型，也不将作者或同行觉得合理当成经验验证 |
| Novak & Cañas, 2008，[The Theory Underlying Concept Maps and How to Construct and Use Them](https://cmap.ihmc.us/docs/theory-of-concept-maps.php)：Introduction 和 Constructing Good Concept Maps 的焦点问题段落 | 关系词形成可理解命题，焦点问题限定图的用途 | 仅借鉴表征方式。研究中概念等价、因果和理论有效性需另外论证，不能从图的结构推出 |

上述来源仅阅读所列相关段落，不是整套文献的系统性方法评估。术语对照中的证据分级、正反例检查及“允许不融合”的处理是本次任务设计，不是上述作者提出的统一流程。

## 设计取舍及可反驳预期

| 设计 | 理由与前提 | 哪种结果会否定预期 |
|---|---|---|
| 分开标签、构念和观测指标 | 相同字词或量表可能承担不同理论角色 | 仍把指标名称相同写成概念等价 |
| 显式区分等同、包含、重叠和类比 | 降低合并时丢失理论限定的风险 | 合并后无法还原原作者意思或反例 |
| 保留分析层次与作用范围 | 某层次的关系未必可迁移到其他层次 | 将群体规律直接归给个体，或略去定义域 |
| 新框架逐条写出桥接假设和证据状态 | 使新增推断可检查，而非藏在连线中 | 新解释被当作原理论已经证实的结论 |
| 根据任务保留不可融合的框架 | 某些分歧来自真实不相容前提 | 为统一命名消除重要分歧，或只换术语却无解释增益 |
| 依据研究类型安排检验 | 解释、预测、证明的成功标准不同 | 所有理论都被强套统计实验，或经验命题只靠自洽获得确认 |

这些设计未经过跨学科对照试验，不主张具有已证明的普遍优势。

## 创建者场景走查

以下为人工推演，不是独立运行评测。

| 输入 | 走查结果 |
|---|---|
| “比较两个学派对同一概念的定义，再形成工作框架” | 先保留原定义和层次，再给带条件映射；工作定义注明任务选择 |
| “这个术语的中文怎么译” | 没有比较需求时不启动全套理论综合 |
| 两个领域使用同一个词但对象不同 | 不自动合并，标出对象及关系缺项 |
| 不同术语在给定条件下具有相同判定规则 | 核查可替换范围，保留版本和例外后才称局部等同 |
| 两份研究使用相同问卷却提出不同构念 | 分开操作化与理论定义，不因指标一致宣布概念相同 |
| 要求把互相矛盾的理论强行统一 | 定位前提冲突，交付并列或条件框架，不制造已达共识的假象 |
| 形式化模型与解释性理论比较 | 分别记录定义域/证明条件和材料语境，说明对应层次与不能迁移的判断 |

已完成上述作者场景走查。2026-10-25，另由未参与编写、没有继承本次对话历史的评估者，基于 Liu《Lost in the Middle》与 Veseli《Positional Biases Shift as Inputs Approach Context Window Limits》的指定版本完成有限真实试用，覆盖概念对齐、研究关系及主张交叉核验，并从原文定位出不应抹平的条件差异。没有运行模型实验；未验证跨学科表现、完整研究效果或相对性能。执行记录与结构检查保存在本次批量创建的独立检验材料中，不作为本技能的运行依赖。

# 调研记录字段

用于保存可追溯的检索、筛选和综合过程。按任务规模选表或结构化文本；小任务可以合并，但不要丢失“查询—材料—主张”的对应关系。这里只定义字段，不预填看似真实的论文或检索数据。

## 检索记录

| 字段 | 记录方式 |
|---|---|
| 检索编号与目的 | 对应子问题，或术语校准、补查反证、更新版本 |
| 实际日期、平台与数据库 | 平台和数据库能区分时分别写；网页检索注明域名限制 |
| 实际查询 | 完整关键词、布尔式或语义检索问题；不同查询分别保存 |
| 限制 | 年份、语言、文献类型、地域、排序；未限制也说明 |
| 返回与查看范围 | 工具实际返回的条目/页次；总命中不可得时写未知 |
| 结果去向 | 纳入/候选/排除的记录编号，查询修正原因、待补查点 |

直接打开已知文献、追查引文和手工浏览也记为来源获取动作；不要包装成执行过数据库检索。若搜索总数、导出数和实际筛选数不同，分别标明。网页搜索及语义排序会变化，记录可追溯不等于保证完全重现排名。

## 文献与研究关联表

| 字段 | 记录方式 |
|---|---|
| 记录编号 / 研究编号 | 一个报告一个记录；同研究的不同报告关联到同一研究编号，关系待核则明确标注 |
| 标识与书目 | 原题名、作者、年份、DOI/学科编号或稳定链接；没有标识不编造 |
| 来源与状态 | 正式论文、预印本、专著、综述等；发表页和实际使用版本 |
| 获取与筛选 | 来自哪个查询/引文；纳入、排除或待定及具体理由 |
| 阅读范围 | 元数据、摘要、指定章节、全文、附件；只写实际读过的部分 |
| 可见更新 | 实际查过的更正/撤稿/版本信息，日期和入口；未核查写未核查 |

## 主张与证据表

| 字段 | 记录方式 |
|---|---|
| 子问题 / 主张编号 | 使同一结论可关联多个来源，并看出冲突 |
| 主张类型 | 作者报告、本次核对、综合推断 |
| 方法与条件 | 按学科保留对象、数据/材料、比较、假设、指标或论证前提 |
| 结果 | 尽可能按原文表达；数值附单位、不确定性及比较对象 |
| 原文定位 | 页码、章节、表图/定理号、段落或可稳定定位的标题；不要只填论文首页链接 |
| 支持关系 | 支持、限制、反驳、背景或尚不确定；说明关系成立的条件 |
| 局限与依赖 | 方法限制、未读部分、共享数据/样本、替代解释 |
| 综合判断 | 能支持什么、不能支持什么、还需什么证据 |

字段缺失时区分：原文未报告、尚未读取、访问不可得、不适用。证据不足是结果，不是待模型自动填补的空格。

## 输出取舍

- 快速概览：范围说明、关键文献短表、核心结论的来源与限制、简短检索记录。
- 标准调研：保留上述记录及跨文献综合；长表可作附件，不挤占主要论述。
- 文件格式由任务决定；普通 Markdown 表即可，不默认创建电子表格、数据库或多份重复文件。
- 参考文献中的原题名保留可检索性；译名可另附。只生成已核验字段，不补造卷期页码或 DOI。

## 本技能的设计推断

| 设计 | 理由与前提 | 何种情况需要修正 |
|---|---|---|
| 先核实异常与比较条件，再生成问题 | 防止把版本、测量或处理差异当作科学矛盾 | 已有材料明确解释了差异，却仍将其列为未解冲突 |
| 把知识收益与执行可行性分开 | 有价值的问题可能暂不可执行；容易实施也可能缺少意义 | 排序只反映数据易得或预计文章数量 |
| 每个问题写不同答案会改变什么 | 让选题具有可评价的认知目标 | 无论结果如何，问题卡都不改变任何判断 |
| 定向近邻检索只做初筛 | 本任务负责提出问题，不承诺穷尽先前工作 | 用初筛未检出直接宣布新颖性 |
| 按学科选择回答形式 | 保留理论、质性、历史等研究的不同论证要求 | 迫使所有问题转成数值指标或随机实验 |

这些规则是本次提出的工作流设计，尚未证明优于现有选题方法。

## 创建者场景走查

以下为人工推演，不是独立执行评测。

| 测试输入 | 检查的决策与走查结果 |
|---|---|
| “根据几篇论文中的冲突找值得研究的问题” | 应触发；先核实冲突条件，给出问题、依据和可判别的回答路径 |
| “给这个研究项目起一个吸引人的名字” | 不应触发；不扩成选题与证据检索 |
| “两篇论文结论相反”，但对象和测量不同 | 将条件差异显式列出，不能直接宣布未解矛盾 |
| “只看我提供的三篇材料，找未解决的问题” | 在集合内形成候选，不能声称外部研究没有答案 |
| 要研究概念史，无法安排干预实验 | 采用原始材料、语境和竞争解释，不因不可实验化而否定价值 |
| 用户给了明确主题但未给候选数量 | 采用与证据相称的候选数，不先发数量问卷 |

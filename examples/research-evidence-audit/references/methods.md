# 方法依据与检验边界

核查日期：2026-10-25。以下是构建技能的材料，不是运行时待审查研究的证据，也不是必须逐项阅读的固定书单。

| 来源与实际阅读范围 | 支持的规则 | 改编与边界 |
|---|---|---|
| [Cochrane 第 8 章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-08)，Key Points、8.1、8.2.1–8.2.3 相关段落 | 评价以具体结果为对象，区分目标效应，判断需有书面依据；随机化、缺失和报告选择是不同问题 | 原工具针对随机试验。只提炼“结果—方法—判断”的工作方式；本技能通用检查不构成正式 RoB 2 评价，未全文核查每个领域算法 |
| Hernán、Hsu、Healy，2019，[Data science is science’s second chance to get causal inference right](https://arxiv.org/abs/1804.10846v6)，作者稿 PDF 第 4–9 页（任务分类、Prediction vs. Causal inference、示例与决策部分） | 区分描述、预测与因果任务；因果分析须交代领域假设，自动按关联选调整变量可能造成偏差 | 迁移为主张类型与识别策略检查；未把论文示例中的变量关系固化到其他课题，也不声称它给出了所有识别方法的检查清单 |

原论文稿链接：[PDF](https://arxiv.org/pdf/1804.10846)。未声称逐字比对期刊最终版。曾尝试的目标试验 PMC 页面仅返回验证页面，Harvard 旧教材入口跳转作者简介；两者均未作为已读方法正文。

## 本次设计及可否定的预期

- 把“主张类型—依据—推理环节—结论影响”作为最小审查单位，是本次设计；预期减少泛泛批评。若不能指出疑点影响哪个结论，应收窄或删除该疑点。
- 理论、仿真、质性与人文分支是跨类型工作流设计，未从医学偏差工具推出统一评价标准。若换研究类型仍强套随机化或显著性，应修正路由。
- “支持有限、无法判断、直接反证”用于区分证据状态；若未知材料被当作已证实缺陷，说明设计没有得到正确执行。
- 不按缺陷个数打总分；优先级来自缺陷对具体主张的影响。一个局部报告遗漏不能自动推翻所有发现。

## 创建者场景走查

本表为人工推演，非独立执行评测，未使用真实研究任务实测。

| 场景 | 走查结果 |
|---|---|
| “检查这篇论文由相关性推出政策效果是否成立” | 应触发；先定义目标效应，查看识别策略和混杂/选择假设，再给有条件结论 |
| “只翻译这段摘要” | 不自动触发全面方法审查 |
| 模型预测很准，因此某输入是因果机制 | 预测分支不能支持该推论；需另核因果与机制证据 |
| 随机试验没有报告结局缺失情况 | 区分未报告和已知缺失；核对协议/附录，保留判断限制，不直接判所有结果无效 |
| 定理在有限维条件下证明，却用于无限维 | 走定义与假设分支，核对推广依据，不用医学评分表 |
| 无原始数据，只能读论文 | 可以检查论证与报告，不能声称已独立重算 |

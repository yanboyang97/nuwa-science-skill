# 科研能力方向与设计提示

在需求宽泛、需要补充遗漏能力或选择组合方式时按需阅读。以下方向都可以生成专业 skill；它们是候选，不是必建清单、固定学科分类或一条强制流水线。

## 从用户的问题选择能力

| 能力方向 | 可帮助完成的工作 | 设计前需要区分的情形 |
|---|---|---|
| 文献调研 | 检索、筛选、精读并组织与问题相关的证据，保留检索范围与来源 | 快速探索、系统性搜集、持续追踪对覆盖面和成本要求不同 |
| 文献串联 | 连接概念、假设、方法、证据和发展脉络，形成有依据的关系 | 引用谱系、论证链和跨主题综合并非同一任务；联系需说明依据 |
| 不同研究的交叉评议 | 用相互相关的研究检查主张、假设、方法与证据，识别支持、矛盾和互补 | 同领域对照与跨领域迁移的可比性不同；多论文或多角色不自动构成独立验证 |
| 科研问题发现 | 从未解矛盾、理论缺口、失效边界和重要需求中形成可研究问题 | 头脑风暴、选题筛选、确定正式研究问题所需证据不同 |
| 研究空白与新颖性核查 | 将候选贡献与已有工作比较，界定已知内容和仍待验证的差别 | “尚未检索到”不足以证明“无人研究过”；需明确核查范围 |
| 概念对齐与理论综合 | 澄清定义、术语、分析层次与前提，比较不同解释或形成综合框架 | 同名概念可能不同，异名概念可能相近；类比不等于机制相同 |
| 证据、方法与因果审查 | 判断证据能支持多强的结论，识别偏差、混杂和方法局限 | 理论证明、观察研究、实验研究与模拟的证据标准不同 |
| 假设、反例与可证伪性 | 提出竞争假设，寻找反例，确定能够区分解释的观察 | 自由探索与检验已有假设不同；需给出可能推翻主张的结果 |
| 研究方案与评价设计 | 选择研究路径、对照、指标、资源和判定条件 | 理论推导、数据分析、实验与仿真不共用固定设计模板 |
| 复现与结果核验 | 对齐方法、代码、数据、配置和结果，定位复现差异 | 逐项复现、独立验证和仅核对报告的结论范围不同 |
| 论证组织与学术写作 | 将问题、证据、推论和贡献组织成面向目标读者的清晰论证 | 概念解释、论文写作、研究综述与审稿回复的用途不同 |
| 研究路线与资源取舍 | 比较研究方向、信息收益、可行性和机会成本，安排下一步 | 要明确目标与资源约束；不以容易取得的指标替代科学价值 |

这些区分用于选择合适的默认方案，不作为逐项问卷。未另行指定时：文献调研采用围绕问题的检索与证据整理；文献串联采用概念、假设、方法和证据之间的关系综合；交叉评议采用可比条件下的支持、冲突与互补分析；问题发现采用有依据、值得研究且可回答的候选问题生成。

简要说明采用的含义即可推进；只有任务无法合理匹配这些默认解释时才提问。各能力需要的建设材料和运行数据见 [来源与数据指引](sources-and-data.md)。

## 补充建议的表达方式

向用户说明：

> 本次默认采用……，理由是……。可选补充是……，它能带来……，会增加……；需要时可以纳入。

候选补充应具体对应需求，例如：

- 文献调研若需要跨论文比较，概念对齐和证据记录可能成为必要的衔接。
- 文献串联若用于提出新解释，需要区分已有证据支持的关系与尚待检验的推断。
- 问题发现若要形成可执行课题，可能需要新颖性核查、可证伪性和可行性筛选。
- 交叉评议若用于结论取舍，需要先检查数据、任务、假设和指标是否可比较。

满足当前目标所必需的衔接默认采用最小实现并说明。新增独立能力列为可选，不要求用户逐项作答，也不自动创建全部候选。

## 组合而不混淆职责

组合方案应注明每个专业 skill 的调用条件、输入、输出，以及下一项需要哪些内容。只保存衔接所需的主张、依据、限制和未解决问题，避免反复复制整套材料。

例如，用户需要从分散论文中发现研究问题时，可以提议“文献调研 → 文献串联／交叉评议 → 问题发现”。这只是可能方案；若用户已整理好材料，应从真正缺少的能力开始。证据冲突可以触发定向补查，不必重走完整流程。

若不同 skill 对同一问题给出不同判断，回到各自依据和适用条件，不用简单投票代替核查。默认组合只服务于当前目标；改变目标或明显扩大的方案作为可选扩展，核心方案无法确定时才提问。

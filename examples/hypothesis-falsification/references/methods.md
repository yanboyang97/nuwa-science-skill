# 方法依据与检验边界

核查日期：2026-10-25。以下资料支持部分操作原则；竞争假设矩阵、反例分支与停止条件是本次工作流设计，不冒称某一来源验证了整套技能。

## 已核查的一手来源

| 来源与阅读范围 | 采用的原则 | 边界 |
|---|---|---|
| [Center for Open Science：Preregistration](https://www.cos.io/initiatives/prereg)，What is Preregistration、Hold out data-sets or split samples，以及关于计划外分析和已有数据的 FAQ 可见段落 | 区分计划与事后探索，明确数据是否参与假设生成；按任务考虑保留或新增验证材料 | 不是所有研究都必须预注册；登记、划分数据或预先写计划本身不保证有效推断，不自动执行外部注册 |
| [ASA：Statement on Statistical Significance and P-Values 官方发布说明](https://www.amstat.org/asa/files/pdfs/P-ValueStatement.pdf)，第 1–2 页，重点第 2 页六原则 | 不以单个 p 值阈值裁定科学结论，区分显著性、效应大小与假设真假概率 | 阅读的是 ASA 官方发布说明及其中完整列出的六原则，未声称读过相关讨论论文全集 |

只采用与本技能直接相关的原则，未把来源页面中的宣传性效果表述当作已验证的普遍效果。

## 设计推断

| 工作流规则 | 设计理由与前提 | 失败信号 |
|---|---|---|
| 先识别命题量词与类型 | 反例的逻辑作用取决于主张形式 | 用一次失败否定概率主张，或用有限搜索证明全称主张 |
| 将假设写成不同条件下的差异预期 | 让比较对应可观察的信息 | 所有假设对全部可行观察给出相同预期却宣称已区分 |
| 反例先核验前提 | 避免拿域外实例、实现错误或数值误差反驳原命题 | 反例不满足原假设仍被保留为有效反驳 |
| 把检验失败分解为主张和辅助条件 | 观察与理论之间存在测量及实现环节 | 任意修改辅助假设以免主张受损，且没有新的可检查后果 |
| 选择与研究类型相符的检验 | 经验检验只是研究论证的一类方式 | 将历史解释或规范性论证因不适合随机实验直接判无价值 |

这些规则是逻辑与研究设计原则的操作化，不代表独创理论，也没有比较实验支持其性能优于既有流程。

## 创建者场景走查

以下为人工推演，非真实科研任务执行。

| 输入 | 检查的决策与走查结果 |
|---|---|
| “给这个现象提出竞争假设并设计区分检验” | 应触发；各假设对应不同预期、前提和检验状态 |
| “帮我润色假设段落但保持含义不变” | 不自动扩为新假设生成或实验设计 |
| “平均提高准确率”的方法在一个样本失败 | 先保持平均效应主张，不把单个例外写成逻辑反驳 |
| 全称定理的候选反例违反了定义域条件 | 不算有效反例，指出违反的前提 |
| 同一批数据既生成假设又检验，得到很小的 p 值 | 标记探索过程和分析选择，不写成独立确认 |
| p 大于约定阈值，用户要求结论“没有任何效应” | 检查精度及等效判断条件，现有材料不足则不支持该结论 |
| 两个解释在当前所有观测上相同 | 报告不可区分，提出需要的新条件；不任意选赢家 |
| 问题属于规范性判断 | 转为适合的论证比较，不机械应用经验可证伪标准 |

真实小任务：2026-10-25，未参与编写的试用者读取 R 官方 Anscombe 数据，保存计算前判断规则，实际计算摘要、曲率与逐点删除诊断并绘图，区分摘要充分性反例与未识别的随机生成机制。保留了10%敏感性警报在多组触发的结果和事后扩展标识；没有为符合预期改阈值。已知经典案例且先读过数据，不是盲法发现或独立确认；未验证跨学科表现、统计决策质量或研究收益。记录与计算产物单独保存。

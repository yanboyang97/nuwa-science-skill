## 本次设计选择

- 从“结果会改变哪个判断”倒推测量和对照，意在减少做完研究却无法区分解释的情况。如果不同解释在所有拟测指标上的预测均相同，应承认设计无法鉴别或修改测量。
- 对实验、观察、预测、理论、仿真和质性分别设必要关注点，保持跨课题复用。各分支是设计入口，不能替代具体领域的完整方法学。
- 未知资源和样本量输入用条件、范围及试点表述，避免伪精确计划。若实际计算依赖未经说明的方差或效应假设，应补明后重算。
- 设计与执行状态分开，避免把“预计可行”写成“运行成功”。方案的可执行性和结论有效性都需要后续真实检查。

## 创建者场景走查

这是作者人工推演，未做真实任务执行或独立对照评价。

| 场景 | 走查结果 |
|---|---|
| “设计比较两种算法在跨域任务上可靠性的方案” | 应触发；定义跨域测试、数据隔离、公平基线、可靠性及成本，而非只选最高平均分 |
| “按照这份既定配置运行脚本” | 不自动重做研究设计；若需复核既定结果，转入执行/复现任务 |
| 用户未给效应大小或预算 | 保留范围、依赖和可核查假设，不能凭空确定样本量与工期 |
| 相同数据上反复调到显著后要求验证性结论 | 标为探索性选择，设计独立检验或适当校正，不回填为预先计划 |
| 目标是理论命题的成立边界 | 定义假设、引理和反例，不套随机分组或功效分析 |
| 只要求设计访谈研究 | 从材料选择、访问、解释过程与负例设计，统计显著性不是完成门槛 |
| 很多重复测量来自同一个对象 | 保留依赖结构，不把重复测量数当成独立样本量 |

真实小任务：2026-10-25，非编写者为20 Newsgroups完成具体研究协议，并实际校验归档、训练/测试成员数和100篇训练材料；没有执行模型训练。试用者意外读过作者走查，故不称盲试。独立复核发现机器配置把 max_df=1.0 序列化成整数1，改变了参数含义；保留原件后修正，并在交付步骤补充保存后配置的值、类型、单位与库语义一致性检查。实际重载原/新配置及小语料频率检查已确认这一差异；未执行 scikit-learn 的实际拟合，后续仍需环境与运行闸门。该提醒由本次转录错误提炼，不代表原科学设计普遍失效；[参数语义依据](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html)。详细失败、修正和复查随任务保存；未验证完整实验或跨领域研究成效。

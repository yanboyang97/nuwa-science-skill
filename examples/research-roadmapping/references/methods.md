## 本次设计选择与失败边界

- 把科学价值与当前可实施性分开，是为避免“便宜易做”取代科学目标。若重要方向因暂时缺资源被写成毫无价值，需修正表述及排序依据。
- 以“某个检查的结果是否改变后续选择”作为定性信息收益判断，是本次提出的工作流启发式。没有概率与效用数据时不计算精确期望信息价值；它不保证找到全局最优路线。
- 对权重与未知条件做敏感性检查，预期暴露脆弱排序；若合理条件改变就翻转推荐，输出应转为条件化建议。
- 阶段门槛依据证据与产物，依赖共享和资产复用明确记录。真实成本、机会成本和科学贡献仍须在执行中验证。

## 创建者场景走查

下列为作者人工推演，尚无真实路线决策的长期结果或独立评价。

| 场景 | 走查结果 |
|---|---|
| “只有两周资源，比较三个研究方向先做哪个” | 应触发；区分价值与两周内可获得的证据，以最小判别步骤安排先后 |
| “把已定会议按时间排进日历” | 不触发科研路线比较 |
| 预算和设备可用性都未知 | 给资源情景和待核依赖，不编金额或确定工期 |
| 第一名只在一种任意权重下成立 | 标出排序敏感，给条件化推荐及最有用的补查 |
| 价值很高但关键数据拿不到 | 保留科学价值，当前选择转为解除数据依赖或缩小目标 |
| 一个便宜试点无论结果如何都不改变下一步 | 不因便宜就推荐先做，重新评估其信息用途 |
| 两个方向共享同一数据和失效假设 | 只合并可复用的一次性数据取得成本，分别计后续分析成本；不把组合误说成风险独立分散 |
| 两条路线共用设备，各需运行10小时 | 总设备需求仍为20小时，并检查排期与容量；共用设备不等于共用同一次运行 |

真实小任务：2026-10-25，非编写者实际核查20 Newsgroups资料、具体模型卡和CPU支持文档，在本次设定的1人、2周、10 CPU核时约束下比较三条路线，交付共享/增量账本、条件排序、阶段门槛及转向条件。试用者意外接触作者走查，故不称盲试；实际产物另经复核。未安装训练依赖、下载权重或计时模型，预算分配不是耗时预测；未验证长期收益、资源预测精度或跨学科效果。详细决策记录单独保存。

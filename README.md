# 女娲 · 通用科研元 skill

女娲根据用户需求，设计、创建、组合和改进专业科研 skill。生成的专业 skill 用于完成相应科研工作；元 skill 负责把能力需求转成可以使用和检验的方法。

入口：[SKILL.md](SKILL.md)。技能标识仍为 huashu-nuwa，版本为 3.1.1。

## 适用范围

跨课题、跨研究方向使用。当前项目、最近讨论和所给材料只提供背景，不自动成为元 skill 或专业 skill 的长期边界。用户明确需要课题专用能力时再限定。

可以创建文献调研、文献串联、不同研究的交叉评议、科研问题发现等 skill，也可以按需要创建概念对齐、新颖性核查、证据审查、假设检验、研究设计、复现、学术写作和研究路线等能力。

这些是开放的候选方向，不是每次都要创建的清单。按问题选择，必要时复用或组合已有能力。

## 默认配置与合作方式

首次启用时，用两三句话说明默认配置和可改选项，随即开始。默认采用跨课题范围、优先复用、最小可用专业 skill、已有材料优先并补查公开来源、小范围检验、跟随对话语言、更新沿用原路径。新建默认保存到当前项目的 .agents/skills/。

范围、材料类型、检索深度、输出和保存位置都可改。已有要求优先；未说明的事项采用合理默认值，不把配置表变成问卷。只有缺少关键输入或几种解释无法合理取舍时，才集中询问。

当前目标内的必要补充采用最小方案；其他能力作为可选建议，不阻塞交付。用实际任务检查专业 skill，并根据失败记录改进；条件不足时说明未实测。

## 去哪里找、找什么

[来源与数据指引](references/sources-and-data.md)分两层列明资料类型、具体入口、提取内容及用途：

- 构建能力：方法论文、教材手册、示范研究、原始讲座与访谈、研究者博客、实验室实践、公开评审、失败复盘和带反馈的案例。
- 专业 skill 运行：文献元数据与全文、概念和假设、方法与结果、引文关系、代码数据、研究计划、评审修订及反证。

默认按目标选择相关材料，明确哪些是作者报告、经验建议、独立复核或推断；不要求每次搜齐所有类型。检索入口用于发现材料，重要判断回到原文和实际产物核查。

## 使用示例

- “用女娲，为我创建一份通用文献调研 skill，先说明默认配置，再开始。”
- “我想提升文献串联能力。先采用你认为合适的默认解释和产出方式，无法确定时再问我。”
- “帮我设计一个不同研究之间交叉评议的 skill，考虑概念、假设、方法和证据的可比性。”
- “我已经有文献调研 skill，现在需要从文献中的矛盾与缺口发现研究问题。请判断复用、组合还是新建。”
- “这个专业 skill 在以下任务中出现了误判。请定位原因、改进规则并检查受影响的行为。”

普通的论文总结或一次性研究请求，不自动转为创建 skill。生成后如何安装和保存，应遵循用户选择与现有约定；跨课题适用不等同于修改全局设置。

## 安装与文件结构

在支持本地 Agent Skills 的环境中，将整个 huashu-nuwa 文件夹放入当前项目的 .agents/skills/，保持以下相对结构。在 Codex 中可用 $huashu-nuwa 调用，也可以直接要求使用女娲创建科研 skill。

~~~text
huashu-nuwa/
├── SKILL.md
├── README.md
├── LICENSE
└── references/
    ├── capability-map.md
    ├── extraction-framework.md
    ├── skill-template.md
    └── sources-and-data.md
~~~

本包只有指令与参考文档，无需执行安装脚本。创建和保存专业 skill 需要相应文件权限；联网检索和文献库连接按任务需要使用，不依赖某个必装插件。

## 验证范围

当前版本完成了文件格式、包内引用、内容与发布文件检查。真实科研任务中的收益仍需实际试用验证，不能将结构校验当成效果证明。

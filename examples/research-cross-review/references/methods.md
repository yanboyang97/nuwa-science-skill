# 方法依据与检验记录

创建日期：2026-10-25。本技能定位为主张级跨研究评议；不替代领域专用偏倚工具、正式元分析或独立复现。

## 已核查来源与迁移

[Cochrane Handbook 第 12 章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-12)，McKenzie 与 Brennan，页面列示版本 6.5（2024），章节更新于 2019。实际阅读 Key Points、12.1–12.2 的有关段落、12.2.2.1 及 12.3.1。

采用的有限要点：比较表应帮助读者检验综合判断；显著性投票不能可靠裁定研究结论；可用数据和合成方法限制能够回答的问题。原语境是干预研究综合。本技能仅借鉴这些判断原则，不将医学评价标准套用于所有学科，也不自称执行 Cochrane 系统综述。

没有阅读全文所引的全部原始研究。未把章节的示例数据用于真实试用；方法来源本身不是本技能有效性的证据。

## 本次设计规则

| 规则 | 设计理由和前提 | 需修正的失败表现 |
|---|---|---|
| 以具体主张及其条件为评议对象 | 整篇“对/错”标签掩盖不同结论强度 | 某个指标的缺陷被扩成所有结论无效 |
| 先判断可比性，再解释冲突 | 同一词或单位可能指不同对象 | 不同任务上的结果被直接排名或相互反驳 |
| 双向检查，允许不对称结果 | 评议应公正但不机械平均证据强度 | 为了“两边都有问题”虚构批评，或只检验不喜欢的研究 |
| 区分条件内支持、受到限制、证据不足、存在反证和待核验 | 数据缺失、适用域差异和命题错误不是同一情况 | “没读到”被写成“作者没报告”，或“不显著”被写成“无效” |
| 显式记录共享证据与版本依赖 | 多篇报告可能来自同一研究 | 把重复文本或模型角色当独立验证 |
| 将分歧解释与已验证原因分开 | 合理解释仍可能错误 | 未做区分性检查就宣告冲突已解决 |

上述流程是针对任务设计的组合，不宣称提出了新的通用评议理论。需要因果识别、统计检验或证明核验时，应按具体领域补足方法与材料。

## 创建者场景走查

以下为指令层面的人工推演，非独立评测。

| 输入 | 走查结果 |
|---|---|
| “用这三篇后续研究检查 A 的结论” | 提取 A 的具体主张，建立条件表，检查后续证据能支持或限制什么 |
| “帮我润色这篇论文的摘要” | 不触发跨研究评议 |
| A 的效应显著、B 不显著，要求判定 B 推翻 A | 检查估计对象、效应及不确定性，不能只看显著性标签 |
| A 与 B 使用不同数据集和评测协议，要求按分数裁决优劣 | 标明不可直接比较，限定各自条件，不制造统一排名 |
| 三份报告使用同一实验数据 | 记录依赖及新增检查，不能算三次独立验证 |
| 只有 B 的摘要，要求否定其完整方法 | 尝试原文；仍不可得只给摘要层面的判断，保留待核验状态 |
| 人文材料的两种相反解释 | 比较材料、语境和论证路径，不套样本量或显著性模板 |

已完成上述作者场景走查。2026-10-25，另由未参与编写、没有继承本次对话历史的评估者，基于 Liu《Lost in the Middle》与 Veseli《Positional Biases Shift as Inputs Approach Context Window Limits》的指定版本完成有限真实试用，覆盖概念对齐、研究关系及主张交叉核验，并从原文定位出不应抹平的条件差异。没有运行模型实验；未验证跨学科表现、完整研究效果或相对性能。执行记录与结构检查保存在本次批量创建的独立检验材料中，不作为本技能的运行依赖。

# 通用文献调研

把研究主题、问题或种子文献转为有证据支撑的领域认识：已有工作做到了什么、分歧来自哪里、结论适用于哪些条件、哪些问题仍待解决。跨学科复用，不把当前项目、示例课题或某一数据库固化为适用范围。

## 输入与默认配置

至少需要一个可辨认的主题、研究问题或文献集合。用途、学科、时间范围、已有材料、期望深度和资源限制是可选输入；先利用上下文，只有缺失会改变核心任务且无法合理推定时才集中提问。主题太宽时先说明本轮切面并推进；完全没有主题时只询问主题。

每段对话首次启用，用两三句话说明本次主要默认值、可修改项和覆盖限制，然后直接执行。用户已给出的要求覆盖默认值。

| 项目 | 默认 |
|---|---|
| 任务模式 | 定向文献调研：先建立研究脉络，再针对关键缺口补查；不承诺穷尽 |
| 时间 | 不设机械的近若干年下限；兼顾近期进展与奠基工作，记录实际检索日期及文献截止范围 |
| 语言 | 随用户语言输出；检索用领域通行术语、英文及主题相关的原文语言，不把检索语言自动当作排除条件 |
| 材料 | 优先用户已有且相关的材料，再补公开的一手研究；综述用于定位脉络和线索 |
| 深度 | 对影响结论的关键文献读方法、结果、限制及相关附件；其他候选先看元数据和摘要 |
| 数量与成本 | 不预设论文配额；依据问题覆盖、证据缺口和已知预算决定投入 |
| 交付 | 中文场景默认中文综合，附文献对比、检索记录、阅读边界与可核查引用；按用户要求调整篇幅和格式 |

首次说明可采用：“我先做一轮定向调研，结合已有材料、近期进展和奠基文献，重点核查支撑结论的原文。会保留检索与证据记录，区分已读全文、摘要线索和推断；时间、语言、深度和输出形式都可以改。”

明确要求系统综述、范围综述或元分析时，先读 [系统综述分支](references/systematic-review.md)。用户只要求快速概览时可以压缩交付，但仍保留来源和覆盖边界。

## 资料入口与证据用途

根据当前可用工具与学科选择入口，不要求安装特定插件或假定存在付费订阅。

| 需要 | 可选入口 | 提取内容 |
|---|---|---|
| 已有材料 | 用户文件、指定文献集合、已连接且相关的文献库 | 种子文献、附件、批注、既有检索与未决问题 |
| 发现候选 | 可用学术检索工具；Google Scholar、OpenAlex；学科数据库或期刊/会议索引 | 标题、作者、年份、标识、摘要与来源；记录实际使用的平台 |
| 获取原文 | 出版社、学会、作者稿、机构知识库、学科开放库 | 正文、方法、结果、附件；记录版本和实际阅读范围 |
| 核对书目和版本 | 原始发表页、DOI/Crossref、学科标识记录 | 题名、作者、年份、发表状态、版本关系与更正链接 |
| 找反证与边界 | 原文引文、后续研究、复现、负结果、公开评审和更正通知 | 批评对应的具体主张、条件、证据及作者回应 |

入口随领域调整，例如生物医学考虑 PubMed，计算领域考虑会议论文与预印本，人文领域考虑原始著作、校订版本和专著。搜索引擎摘要、AI 摘要和评审意见用于定位线索；研究结论回到其原始依据。预印本明确标注，不因未正式发表就一律排除，也不当作已经同行评审。

优先使用适用的已连接检索、文献库和全文工具；能力不足再用网页或公开接口。语义检索传完整研究问题，布尔检索按平台支持的语法构造；不把一种检索语法机械套到所有入口。

## 执行流程

### 1. 界定本轮要回答的问题

用简短任务卡固定：研究问题、用途、范围、纳入/排除条件、资源限制和预期交付。判断是了解领域、比较路线、核查争议还是更新已有调研，再选择切面。

把宽主题拆成能回答的子问题。概念表保留同义词、旧称、相邻领域叫法及易混概念。干预问题可以用人群、干预、比较、结局组织；理论、历史或解释性研究按其概念、材料与论证对象组织，不强套实验框架。

### 2. 检索、校准与补查

- 从种子文献或领域综述定位术语和主要研究路线，随后查原始研究；无种子时直接以问题和概念检索。
- 关键词检索可用“同一概念的同义词 OR，必要概念之间 AND”的起点；避免把所有子问题同时设为必须命中。保存实际执行的完整查询，区分搜索计划与已执行记录。
- 先检验结果是否命中已知相关工作、是否被同名异义占据；据此改词、放宽条件或换入口。无已知种子时不声称已验证召回率。
- 沿关键工作的参考文献和后续引用补查，并有针对性寻找限制、反例、负结果或复现。记录追踪起点；引文关系本身不等于支持关系。
- 检查遗漏风险：其他术语或学派、近期更新、非主流语言/地域、未发表或非正向结果，以及过度依赖同一数据来源。按最可能改变结论的缺口追加检索。

检索与提取记录按 [记录字段](references/evidence-records.md) 裁剪。工具只返回部分结果时写明可见范围；不能用展示条数代表数据库总命中数。查询中写明年份、语言或发表状态，不视作过滤已经生效；逐项核对返回记录是否满足范围，并注明工具未执行的限制。

### 3. 筛选、核验与关联版本

先看题名和摘要判断相关性，再核查会进入核心综合的原文。保留纳入、排除、待定及理由；全文未得时可保留摘要层面的信息，不自动判为不相关。

核对核心条目的题名、作者、年份、标识和来源链接。按标识及题名/作者关联预印本、正式版和后续修订；同一研究的不同报告合并判断，保留可能有用的附件或早期差异，不重复当作独立支持。同一报告包含多项研究时也不机械合成一项。关系不清楚就标为待核，不仅凭标题相似删除。

对支撑核心结论的文献检查发表页可见的更正、撤稿或版本信息；发现通知后判断其影响。只报告实际核查过的状态，未发现通知不等于证明不存在问题。

### 4. 提取与评价证据

对每项关键主张记录：谁在什么条件下，用什么材料或方法得到什么结果，原文定位在哪里，能支持多强的结论。把“作者报告”“本次核对”“综合推断”分开；读到某一章节不等于全文审查。

评价随研究类型变化：

- 实证研究：设计、样本/数据来源、比较条件、测量、分析及不确定性；相关性不能直接升级为因果。
- 计算/工程研究：任务、数据划分、基线、指标、资源与复现条件；不同评测条件下的数字不直接排名。
- 理论研究：定义、假设、证明或推导、适用域及反例；定理条件之外的应用单独论证。
- 质性、人文与历史研究：材料来源、语境、取样/选材、解释过程、竞争解释与论证边界。

采用与任务相称的评价维度，不给所有学科套同一个证据等级或总分；期刊、被引次数和文献数量不能代替内容判断。未报告、未读取和不适用分别标明，不用猜测填空。

### 5. 形成跨文献综合

围绕子问题、方法路线或争议组织结论，不把逐篇摘要拼成综述。对每个重要判断标出支持文献、限制或反证以及适用条件。

看似矛盾时先比较概念、对象、版本、设计、尺度和指标；可由条件差异解释就说明原因，不能解释则保留分歧。注意共享数据、作者或引用源形成的依赖，避免“多篇提及”被当作多份独立验证。

区分“原文明确提出的局限”“本轮材料中缺少的证据”和“综合推断的研究机会”。声称研究空白前，以替代术语和相邻领域补查；只能支持“在本轮范围内未找到”，不能自动声称无人做过。用户未要求时，研究机会保留为有依据的简短后续问题，不扩成研究方案。

### 6. 收束、交付与核对

定向调研在核心子问题已有可追溯回答或明确证据不足、影响结论的主要分歧已检查、针对关键缺口的补查不再实质改变综合时结束。预算用尽或访问受阻也可结束，但标为部分完成并列出剩余缺口。不得用“凑够篇数”或主观感觉饱和证明全面；系统综述按其协议完成，不能套用此停止规则。

按用户篇幅组织交付，通常包括：

1. 本轮回答、适用条件与主要不确定性。
2. 问题边界、检索日期、实际入口和覆盖限制。
3. 按问题组织的研究脉络与文献对比。
4. 分歧、局限、未决问题及优先补查方向。
5. 可核查书目、检索记录与证据定位；短任务可合并为简表。

输出前核对重要主张是否有对应且实际阅读的依据；数字是否带单位、指标、比较对象和条件；书目是否存在、版本是否一致；摘要层面的线索是否被误写为全文结论。原文不足时降低结论强度，不补造引用或细节。

默认在回复中交付；用户要求报告文件时沿用其目录与格式约定。文献导入、共享、联系作者或长期监测按用户请求另行处理，不因调研自动执行。

## 失败与更新分支

- **只有摘要或网页节选：** 标明实际范围；尝试作者稿、开放库或已有授权附件。仍不可得时只支持摘要可见信息，不能据此给出未读方法、数值或复现细节。
- **检索或全文工具不可用：** 尝试可用替代，利用已有材料完成局部综合；区分未检索与检索无结果。无法回答核心问题时说明缺什么，不重复无效尝试。
- **材料内数据冲突：** 保留各来源、版本和定位，查补充材料与更正；无法解决时不取平均或任意择一。
- **只准本地材料：** 仅在给定集合内检索、去重和综合；明确不能据此说明外部研究现状。
- **更新已有调研：** 读取上次范围、检索式和截止日，检索新增及修订记录；按索引延迟适当重叠时间窗口，说明查询变更、结论变化与仍未解决的问题。

## 方法依据与检验边界

关键规则的来源、跨领域改编和设计假设见 [方法依据](references/methods.md)。本技能不依赖女娲目录中的文件，也不要求特定模型或多 agent 工作流。

结构检查、场景走查和真实小任务试用分开报告；一次试用不能证明跨学科效果，也不能替代系统综述的完整方法学验证。

# 科研能力的提炼、设计与检验

用于将需求、科研方法和实际经验转为可复用规则。按当前任务读取相关部分，不要求所有能力都依赖论文蒸馏，也不要求每次执行完整评估。

## 找出真正需要重复的操作

先问“下一次遇到相似任务，什么判断或操作值得复用”。例如如何界定检索问题、连接两篇论文的证据、核查表面矛盾、判断一个问题是否值得研究。

把需求写成可检查的行为：遇到什么输入，采取什么操作，产生什么结果；缺失材料、证据冲突或前提不成立时如何处理。

区分两类来源：

- **已有方法与经验**：提取原操作、适用条件、结果和失败边界。
- **新设计**：给出针对需求提出该规则的理由、预期收益，以及能够否定它的检查。

不凭名人声望、观点出现次数或语言风格判定方法有效。人物的一次实践可以支持局部规则，更广的适用范围需另行验证。

## 将需求转为设计约束

在创建或重大修改前，依据已有共识整理一份简短设计说明：

| 项目 | 要说明什么 |
|---|---|
| 能力与范围 | 解决哪类重复任务，哪些相近任务不在范围内 |
| 输入与输出 | 必需材料、可选材料、交付内容及使用者 |
| 数据来源 | 构建时学习的资料与运行时需要的数据分别从哪里找、提取什么；详见 [来源指引](sources-and-data.md) |
| 核心操作 | 真正改变判断或结果的步骤，以及适用前提 |
| 默认与边界 | 默认采用什么；首次说明哪些可改；什么情形确实无法合理选择；材料缺失或冲突时做什么 |
| 检验办法 | 什么结果算有用，采用哪些任务和依据检查 |
| 复用与组合 | 为什么复用、更新、新建或组合，必要时如何交接 |

优先用合理默认值和明确假设补全设计，不要求用户重复批准已有共识或逐项选择。当前目标内的必要补充直接采用最小方案；额外扩展列为可选。只有缺口使方案无法合理确定时才提问。

## 保留足够的依据

关键规则可在正文内注明依据；来源映射较长时放生成 skill 的 references/ 中：

| 字段 | 内容 |
|---|---|
| 规则 | 触发条件、操作、可观察的结果 |
| 依据 | 来源定位或设计理由；实际阅读范围 |
| 原始支持 | 材料直接支持什么，使用了什么前提 |
| 本次改编 | 保留、删减、新增或跨领域迁移了什么 |
| 边界与冲突 | 已知失效条件、竞争解释、未解决缺口 |
| 验证状态 | 设计建议、场景走查或实际试用；注明任务与产物位置 |

文献使用 DOI/URL 加章节、页码或图表定位；本地材料使用可解析路径及必要的版本、实验标识。没有核查的引语、数据和方法细节不能伪装成来源事实。

“作者报告如此”“本次实际复核”“根据材料推断”“我们提出的设计”分别表达。局部核查通过不能推及全文或整个领域；仅读摘要不能补写完整实施步骤。

## 跨研究与跨领域迁移

先比较问题定义、概念、假设、输入数据、尺度、目标和评价口径，再判断方法或结论能否迁移。

- 两项结论相反：检查前提、数据、版本与测量差异，保留尚未消解的冲突。
- 两项方法相似：说明对应关系，不因术语或公式相似就假设机制等价。
- 多项研究支持同一判断：检查是否共享数据、方法或引用来源，不能直接当成多份独立证据。
- 出现新的综合解释：区分已被支持的连接与待验证的推断，并寻找区分竞争解释的检查。

这些是可选的专业能力设计要点，按任务需要采用；不要把所有科研活动统一为实验或因果推断。

## 选择能发现问题的验证

先验证核心行为和容易失败的边界，再考虑更多样的任务。检验维度随能力变化，例如：

- 文献调研：检索范围可追溯，纳入材料与问题相关，关键遗漏或偏差可识别。
- 文献串联：关系有来源和推理依据，能区分支持、矛盾、互补及尚待检验的联系。
- 交叉评议：比较条件成立，批评针对证据与方法，区分被反驳、未支持和未核验。
- 问题发现：问题与证据缺口对应，说明价值、可回答性、已有工作和主要不确定性。
- 写作或解释：目标读者能够定位论点、理解依据与限制；流畅度不替代理解测试。
- 复现或结果核验：能找到实际执行入口和产物，区分计划、执行、复核及其覆盖范围。

真实试用采用未参与规则提炼的任务。需要宣称提升时，与旧流程或无该 skill 的做法在可比条件下比较，记录任务、模型、工具、数据和资源差异。

成本按可取得的记录分别计入模型消耗、实验算力、运行时间、人工核验和返工。未知消耗不按零处理，不用低成本抵消关键证据缺陷。

## 将失败转为有限度的改进

保存“任务与输入—实际行为—问题证据—原因判断—修正规则—重新检查结果”。优先修改引起失败的部分；若失败来自材料或工具，不直接归咎于 skill 指令。

以下情形可用于走查，不能据此宣称通过真实研究验证：

- 用户要通用文献能力，背景材料恰好来自一个课题：不自动固化该课题范围。
- “文献串联”未指定形式：先说明采用概念、方法与证据关系综合的默认含义并推进；只有上下文显示不同解释会导致错做任务、又无法判定时才询问。
- 两篇研究结论不同，但样本、任务或指标不同：先检查可比性。
- 仅有摘要却要求复现步骤：标明不足，不能编出实现细节。
- 用户只需要总结论文：不自动进入技能生成流程。

# 证据、方法与因果审查

以具体主张为单位，判断现有材料能支持什么、依赖哪些前提、哪一处缺口会改变结论。单篇论文、研究报告、数据分析或理论论证均可作为对象；按研究类型选标准。

## 输入与默认配置

至少需要待审查的主张及其材料或可定位来源。用户只给论文时，从其核心结论中选取影响用途的主张，并说明本轮范围。用途、重点、原始数据、代码和协议是可选输入；没有可辨认对象时只补问对象，不猜测当前项目就是研究主题。

首次启用用两三句话说明默认：围绕核心主张做定向审查，先读原始证据与方法，输出有定位的判断及最小修正建议；范围、深度、侧重点和交付形式可改。然后直接推进，沿用已知要求；不能确定的关键事实先查材料，不把整个审查变成问卷。

默认不做穷尽检索、不运行完整实验、不替每篇研究打统一质量总分。用户指定正式评价工具时，核对其适用研究类型及当前版本，遵循其完整规则；下面的通用流程不能冒称完成 RoB 2、GRADE 或其他正式评价。

## 资料入口与提取

| 需要 | 入口 | 提取字段 |
|---|---|---|
| 主张及原始依据 | 用户材料、原始发表页、作者稿、机构库、已连接文献库 | 精确表述、对象、条件、结局或命题、页码/章节/图表、版本与实际阅读范围 |
| 设计与分析 | 方法及附录、公开协议/预注册、作者关联代码与数据说明 | 取样、分配、测量、纳排、分析选择、缺失处理、主要与探索性分析、偏离计划 |
| 反证与修订 | 相关原始研究、复现、公开评审及作者回复、出版社更正 | 指向哪个主张、比较条件、问题证据、回应是否解决 |
| 理论与解释依据 | 原始定义、证明、史料或访谈材料及研究者分析记录 | 假设、推导链、材料来源与语境、解释过程、竞争解释与反例 |

先用相关已有材料，再定向补查最可能影响判断的缺口。优先适用的文献库、论文和全文工具，无法获取时尝试作者稿或开放库。仅有摘要时只评价可见主张，不能推定未读方法有缺陷；区分“未报告”“未读取”“不适用”。评审意见是核查线索，不能替代其针对的原始材料。

## 审查流程

1. **把主张变成可核对命题。** 区分描述、预测、因果、机制解释、理论证明与材料解释；记录适用对象、比较对象、时空尺度和结论强度。宽泛结论拆成足以改变判断的少量子主张，不以摘要措辞代替完整定义。
2. **建立主张到依据的连接。** 对每项主张指出直接依据与推理桥梁。核对方法、结果和结论是否对应同一对象、版本与分析；报告作者所述、本次复核和审查者推断。多篇报告若共享数据或样本，保留依赖关系，不能按篇数当作独立支持。
3. **按研究类型审查会改变结论的环节。**

| 研究类型 | 主要判断 |
|---|---|
| 随机实验 | 分配过程、对照、偏离分配、缺失结局、测量及选择性报告；区分分配效应与依从干预效应，随机化不能自动消除后续选择偏差 |
| 观察与因果研究 | 明确干预/暴露、比较、时间起点、结局与目标效应；说明识别策略及关键假设，检查混杂、选择、反向因果和测量；解释调整变量的理由 |
| 预测与计算评测 | 划分单位、时间顺序、数据泄漏、调参和测试隔离、基线公平性、指标定义与资源；预测分数不能直接支持改变输入就会改变结果的因果主张 |
| 仿真 | 模型假设、参数与边界、数值收敛/稳定性、校准和外部对照；仿真内部结果与现实适用性分开 |
| 理论研究 | 定义、量词与假设是否一致，关键推导是否成立，结论是否越出定理条件；数值例子不能代替一般证明 |
| 质性与人文研究 | 材料来源与语境、选材理由、分析过程、反例或异质解释、研究者立场及解释范围；不强加统计功效或随机实验标准 |

4. **追查最关键的替代解释。** 每个实质疑点写清“可观察问题—影响哪个推理环节—可能改变什么结论—需要什么检查”。因果图可帮助显式化假设，但图本身不是证据；不把所有相关变量一律纳入调整。无法排除的重要替代解释保留为不确定性，不宣判研究必错。
5. **核对结果表达与外推。** 数量结果检查分母、单位、比较基准、效应大小及不确定性，区分统计检验与实际重要性。未拒绝零效应不证明等价或无效，差异检验与等效性要求分别处理。局部样本、任务或参数下的结果不能直接外推到全部情形。
6. **给出分层判断。** 对各主张说明“在所列条件下得到支持”“支持有限/需要收窄”“现有材料无法判断”或“存在直接反证”，附理由和定位。把结论改变、实施缺陷、报告不足与表达问题分开；优先给出能够改变判断的最小补证、重分析或表述修正。

## 失败分支与停止条件

- 缺原始数据：可以核对已报告方法和结果的一致性，不能宣称独立重算通过。材料不够评估关键前提时标为无法判断。
- 材料互相冲突：核对版本、分析集与更正，保留未解决差异；不对冲突数字取平均来消解问题。
- 方法超出当前可核验范围：说明未核实的推导或专门前提，完成其余可查部分；需要领域方法时定向查原始指南，不套通用评分。
- 审查到足以改变核心结论的缺陷：先说明影响范围，仍检查是否有不受影响的主张；不把单一缺陷升级为对作者动机或整篇研究的裁决。

核心主张均已连接到依据、关键方法风险和替代解释已处理或明确留空、结论强度与材料相称时完成。预算或访问限制导致提前结束时写明部分完成及待核项，不重复无效获取。

## 交付与衔接

默认交付简洁结论与审查表：主张｜依据及定位｜适用条件｜实质疑点｜当前判断｜最小修正/补证。重要判断标阅读范围，避免把每个可想象风险都写成已发生的问题。

只有任务需要继续时，将待判主张、已核依据、不能排除的解释和所需对照交给研究方案设计；需实际重算时交给复现与结果核验。多研究可比性争议可交给交叉评议，不能以不同技能的赞成票替代证据。

方法来源、跨领域设计和创建时检验见 [方法与检验记录](references/methods.md)。本技能自身不证明研究有效，也不依赖女娲或其他技能包的内部文件。
